# Changelog

## 0.1.0

- Independent Windows deployment companion using an external aTrust runtime image.
- Fresh browser authentication on startup; no restoration of old login cookies.
- Keyboard-based form replacement and value checks before a single submission.
- Stop on rejected credentials or revoked sessions instead of repeated attempts.
- Plaintext / Windows DPAPI switch for both VPN and VNC credentials.
- Browser VNC, loopback-only ports, configurable real gateway mapping.
- Synthetic tests, release audit, example-only configuration, MIT original files,
  and explicit upstream attribution/licensing boundaries.
